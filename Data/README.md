## Week09_cvs_sales_yoy.csv — 편의점 매출 동향(품목별)

### 열 구성(7개)

| 열 | 내용 |
|---|---|
| 연월 | YYYY-MM |
| 구분 | · 총계<br>· 대분류<br>· 중분류 |
| 대분류 | · 총계<br>· 식품<br>· 비식품 |
| 품목군 | 아래 「품목군 8행」 목록의 이름 |
| 전년동월대비(%) | 전년 같은 달과 비교한 매출 증감률(%) |
| 조사대상 | · 13개사(2024년 12월까지)<br>· 15개사(2025년 1월부터) |
| 통계표ID | 값을 가져온 KOSIS 통계표 |

### 품목군 8행(매월)

- 총계
- 식품(대분류)
  - 음료 등 가공
  - 즉석(신선일부)
- 비식품(대분류)
  - 생활용품
  - 잡화
  - 담배 등 기타

### 읽기 전에 확인할 것

- 이 파일에는 **증감률만** 있습니다. 매출액과 매출 구성비는 원천 통계표에 없습니다. 중분류의 증감률을 더하거나 평균해도 대분류나 총계의 증감률이 되지 않습니다(품목군마다 매출 비중이 다르기 때문입니다).
- 2025년 1월부터 조사 대상이 13개사에서 15개사로 늘었습니다. KOSIS 통계표 주석 원문은 「조사대상 확대(13개사->15개사)에 따라 통계 단절」입니다. 2024년 12월 이전과 2025년 1월 이후를 이어서 비교할 때는 조사 대상이 바뀐 사실을 함께 적습니다.
- 값은 2026-11-01에 KOSIS에서 조회한 수치이며 반올림이나 가공을 하지 않았습니다. 2026-11-05에 다시 조회해 값이 같음을 확인했습니다. 통계는 뒤에 수정될 수 있으므로 보고서에 인용할 때는 KOSIS에서 다시 확인합니다.

### 사용 방법

- 9주 수업 — 교수 제공 시트 사본을 사용합니다([9주 자료](../Lectures/Week09_노코드_데이터_분석.md) 3.2).
- CSV를 직접 사용할 때 — Google 스프레드시트의 「파일 → 가져오기 → 업로드」를 사용하면 열이 자동으로 나뉩니다(구분 기호 = 쉼표 · 인코딩 UTF-8).
- 출처 표기 예 — 산업통상부, 「주요유통업체매출동향조사」, KOSIS 국가통계포털(DT_11523_300 · DT_115023_300), 2026-11-05 조회.

## Week10_indicators.csv — 경제지표 다섯 가지(월별)

### 두 파일의 차이

| 파일 | 기간 | 용도 |
|---|---|---|
| Week10_indicators.csv | 2024-01 \~ 2026-09(33개월) | 도구를 처음 만들어 실행할 때 |
| Week10_indicators_plus1.csv | 2024-01 \~ 2026-10(34개월) | 한 달이 추가된 파일로 같은 도구를 다시 실행할 때 |

두 번째 파일의 앞 33행은 첫 번째 파일과 같습니다.

### 열 구성(6개)

| 열 | 내용 | 출처(통계표) |
|---|---|---|
| 연월 | YYYY-MM | — |
| 기준금리(연%) | 그 달의 한국은행 기준금리 | ECOS 722Y001 |
| 소비자물가 상승률(%) | 소비자물가지수(총지수, 2020=100)의 전년 같은 달 대비 상승률<br>지수로 계산해 소수 첫째 자리로 반올림 | ECOS 901Y009 |
| 원/달러 환율(원) | 원/미국달러 매매기준율의 월평균 | ECOS 731Y004 |
| 실업률(%) | 경제활동인구조사의 실업률<br>계절 요인을 제거하지 않은 값(원계열) | ECOS 901Y027 |
| 편의점 매출 증감률(%) | 편의점 전체(총계) 매출의 전년동월대비 증감률<br>9주 파일의 총계와 같은 값 | KOSIS DT_11523_300, DT_115023_300 |

### 읽기 전에 확인할 것

- 빈 칸은 조회일까지 그 달의 값이 발표되지 않았다는 뜻입니다.
  - 편의점 = 2026-08부터 빈 칸
  - 실업률 = 2026-10 빈 칸
  - 따라서 지표마다 최신 월이 다릅니다.
- 실업률은 계절 요인을 제거하지 않은 값입니다. 따라서 겨울(12월, 1월)에 높게 나타납니다.
- 소비자물가 상승률은 지수를 전년 같은 달과 비교해 계산한 값입니다. 2026년 7월(2.8%)과 8월(3.1%)은 발표값과 같습니다.
- 편의점 열에는 2025년 1월의 통계 단절(조사 대상 13개사 → 15개사)이 있습니다. 내용은 위 9주 파일 설명과 같습니다.
- 값은 2026-11-11에 조회했습니다. 통계는 뒤에 수정될 수 있으므로 보고서에 인용할 때는 원천에서 다시 확인합니다.

### 사용 방법

- 10주 수업 — [10주 실습 안내](../Lectures/Week10_실습안내.md)의 순서를 따릅니다.
- 내려받기 — 파일을 열고 「Download raw file」을 누릅니다. 코드 파일과 같은 폴더에 저장합니다.
- 출처 표기 예 — 한국은행 경제통계시스템(ECOS) 722Y001, 901Y009, 731Y004, 901Y027, 2026-11-11 조회.
