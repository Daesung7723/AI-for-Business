  - 즉석(신선일부)

### 읽기 전에 확인할 것

- 이 파일에는 **증감률만** 있습니다. 매출액과 매출 구성비는 원천 통계표에 없습니다. 중분류의 증감률을 더하거나 평균해도 대분류나 총계의 증감률이 되지 않습니다(품목군마다 매출 비중이 다르기 때문입니다).
- 2025년 1월부터 조사 대상이 13개사에서 15개사로 늘었습니다. KOSIS 통계표 주석 원문은 「조사대상 확대(13개사->15개사)에 따라 통계 단절」입니다. 2024년 12월 이전과 2025년 1월 이후를 이어서 비교할 때는 조사 대상이 바뀐 사실을 함께 적습니다.
- 값은 2026-11-01에 KOSIS에서 조회한 수치이며 반올림이나 가공을 하지 않았습니다. 2026-11-05에 다시 조회해 값이 같음을 확인했습니다. 통계는 뒤에 수정될 수 있으므로 보고서에 인용할 때는 KOSIS에서 다시 확인합니다.

### 사용 방법

- 9주 수업 — 교수 제공 시트 사본을 사용합니다([9주 자료](../Lectures/Week09_노코드_데이터_분석.md) 3.2).
- CSV를 직접 사용할 때 — Google 스프레드시트의 「파일 → 가져오기 → 업로드」를 사용하면 열이 자동으로 나뉩니다(구분 기호 = 쉼표 · 인코딩 UTF-8).
- 출처 표기 예 — 산업통상부, 「주요유통업체매출동향조사」, KOSIS 국가통계포털(DT_11523_300 · DT_115023_300), 2026-11-05 조회.
