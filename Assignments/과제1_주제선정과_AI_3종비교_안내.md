# 경영경제 AI 활용 입문 — 과제 1 안내

## 1. 과제 개요

| 항목 | 내용 |
|------|------|
| 과제명 | **과제 1 — 주제선정 + AI 3종 비교** |
| 부여와 제출 | 4주 부여 → **6주 제출** (제출 위치와 마감 시각은 수업에서 안내) |
| 분량 | A4 2\~3장 |
| 성격과 배점 | 학기 종합 과제(3회) 중 1회차, **배점 6%** (과제 3회 합산 30%, 강의계획서 기준) |

이 과제에서 정한 주제로 과제 2(1차 조사·분석)와 과제 3(최종 분석보고서)까지 진행합니다. **한 학기 동안 이어 갈 주제를 정하는 과제**이므로, 분량보다 주제 선정에 시간을 쓰시기 바랍니다.

## 2. 트랙 선택 (2-Track)

둘 중 하나를 선택합니다. 우열은 없으며, 관심의 방향으로 고릅니다.

| 트랙 | 대상 | 최종 산출물(14주) |
|:--:|------|------|
| **A. 기업·산업 분석** | 관심 있는 기업 또는 산업 | 기업분석 보고서 (환경 분석 → SWOT → 수익 구조 → 재무 하이라이트 → 제언) |
| **B. 아이디어 검증** | 시도해 보고 싶은 사업 아이디어 | 아이디어 검증 보고서 (문제와 고객 → 캔버스 → 시장성 → 검증 결과) |

## 3. 제출물 구성 (3개 요건)

1. **트랙, 주제, 선정 이유** — 주제 문장에는 시장의 경계를 함께 적습니다(예: "국내 저가 커피 프랜차이즈 시장(채널: 가맹점)"). 선정 이유에는 4주 수업에서 다룬 기준(관심 지속, 자료 존재, 범위 적정)에 대한 자기 점검을 포함합니다.
2. **AI 3종 비교** — 선정 주제로 만든 **같은 질문 하나**를 Gemini, ChatGPT, Perplexity에 동일하게 입력하고, 답변 비교표를 작성합니다. 질문은 수업의 조사 프롬프트 틀(역할, 주제, 요구 정보, 출처 요구, 형식)로 만듭니다.
   - 비교표 권장 구성 — 행: 도구 3종 / 열: **모델과 버전, 실행 날짜**, 핵심 수치, 출처 표시 여부, 기준 연도, 답변 형식, 한 줄 평가
   - 모델과 버전, 실행 날짜를 적는 이유(2주 수업): 같은 도구도 모델이 다르면 답이 달라지므로, 이 두 항목이 없으면 비교가 성립하지 않습니다.
3. **주력 도구 선택과 근거** — 비교 결과를 바탕으로 내 주제에 맞는 주력 도구를 정하고 이유를 적습니다.

## 4. AI 활용 수칙 (3주 수업 내용 — 이 과제부터 적용)

- **모든 AI 답변은 초안입니다** — 그대로 옮기면 감점, 검증하면 가점.
- **출처 확인** — 수치와 주장의 출처가 실재하는지, 원문에 있는지, 1차 출처인지 확인한 흔적을 남깁니다.
- **AI 활용 표기** — 과제 말미에 세 줄로 기록합니다: 활용 도구(모델과 버전, 실행 날짜) / 주요 프롬프트 / 검증 내용.
- **기밀과 개인정보 입력 금지** — 인턴, 아르바이트 등에서 접한 내부 자료, 타인의 개인정보는 입력하지 않습니다.

## 5. 자주 하는 질문

- **주제를 정하지 못했다면** — 세 질문에서 출발합니다: 최근 돈을 쓴 곳은 어디인가 / 일해 보고 싶은 산업은 어디인가 / 불편해서 바꾸고 싶은 것은 무엇인가.
- **세 도구의 답이 전부 부실하다면** — 도구가 아니라 주제 범위의 문제일 수 있습니다. 범위가 너무 넓은지, 좁은지(4주 수업 5절) 점검한 뒤 다시 비교하세요.
- **트랙이나 주제를 바꾸고 싶다면** — 조사를 처음부터 다시 시작하게 되므로 신중히 결정하되, 변경이 필요하다고 판단되면 가능한 한 빨리 수업 시간에 문의하세요.
