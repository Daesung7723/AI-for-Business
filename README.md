### 강의 자료

수업에서 다룬 개념과 AI 시연 결과를 주차별로 정리한 자료입니다. **복습 기준 = 이 자료 + 수업 중 필기.**

각 주차 자료는 **해당 수업이 끝난 뒤 게시**합니다. 시연의 검증 결과와 지문 비판 문항의 해설이 함께 실려 있어, 수업 전에 공개하면 수업 중 확인 활동이 성립하지 않기 때문입니다.
